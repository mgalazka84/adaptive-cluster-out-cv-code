REPRODUCING THE REPORTED DEFAULT-RULE EXPERIMENTS

Public repository:
https://github.com/mgalazka84/adaptive-cluster-out-cv-code
Benchmark implementation and retained runs originate at commit:
0cd531ada86f38ee863fabb2c3d28f114a05289d
The accompanying article pins the full release, including later diagnostic scripts.

The revised paper uses the public default absolute and relative tie guards
of 1e-10, directional loss bounds and intersections of anchored intervals.
Practical, default-tolerance and loose L-BFGS-B omit the terminal Hessian.
A norm-only ablation compares the previous propagation bound. Current results are in
results/accuracy_v2/. Historical development results elsewhere in results/
are retained separately and are not the revised timing evidence.

Use a disposable clone because benchmark commands overwrite their own
output directories. From an unused working directory:

git clone https://github.com/mgalazka84/adaptive-cluster-out-cv-code.git acv_replay
cd acv_replay
git rev-parse HEAD
# For an exact replay, checkout the full release commit pinned in the article.
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r code/requirements-audit.txt
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
export MKL_NUM_THREADS=1

python code/check_math.py
python code/check_boundary.py
python code/check_accuracy_replay.py

The last command checks the archived outputs against the released adaptive
algorithm without repeating timing. Archived per-fold CSV files are gzip
compressed; the readers accept either .csv or .csv.gz.

To rerun all eleven methods and their randomized-order timings:

python code/run_accuracy_benchmark.py --suite original --timing-reps 3
python code/run_accuracy_benchmark.py --suite scale --timing-reps 3
python code/run_accuracy_benchmark.py --suite fresh --timing-reps 3
python code/run_accuracy_benchmark.py --suite lexdec --timing-reps 7
python code/analyze_accuracy.py
python code/analyze_directional.py
python code/profile_accuracy_cost.py
python code/audit_constant_precision.py
python code/analyze_certified_comparison.py
python code/audit_certify_completion.py
python code/audit_reference_precision.py

The fresh plan contains 80 new seeds, including 20 datasets with 30
participants, 24 tasks and eight candidates. All jobs and environment
metadata are recorded in the suite directories. The original and scale
suites contain 140 and nine datasets, respectively; lexdec has two targets.
Figures 5--7 are generated by analyze_accuracy.py. Figures 1--4 are
explanatory schematics supplied separately with the manuscript sources.
The certification-comparison and timing-resolution summaries use retained
timings. Completion and reference-precision scripts are separate diagnostics;
they do not modify the benchmark fits, stopping rule or archived timings.

The external statsmodels fits are archived in results/lexdec/. Their
estimation does not depend on the adaptive stopping rule. The current
endpoint comparisons are in results/accuracy_v2/summary/. To regenerate
external fits, run python code/audit_statsmodels.py; then regenerate the
accuracy summaries with python code/analyze_accuracy.py.

Timings used Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, pandas 2.2.3 and
one-thread BLAS on an AMD EPYC 9V74 under x86-64 Linux. Timings depend on
hardware and load. The 80-digit audit uses mpmath 1.3.0 and tests arithmetic
from binary64 whitened inputs and reconstructs the gradient using an 80-digit
Cholesky factorization of the compressed covariance. QR/compression and the
whitening transform S remain binary64. This is not verified interval arithmetic.
